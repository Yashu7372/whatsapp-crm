These drafts follow the configurable `engineering-deep-dive-v1` structure: engineering tension, concrete problem, explicitly labelled incident with controlled dry sarcasm, failure of naive approaches, system idea, usage boundaries, task snapshots, request journey, decision point, implementation shape, trade-offs, failure path, evidence, proof status, broader usage and one-line takeaway.

All incidents in these five drafts are labelled generalized engineering scenarios. Implementation statements that are not yet linked to source evidence are explicitly described as design intent.
